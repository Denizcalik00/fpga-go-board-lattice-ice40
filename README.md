# FPGA Learning Journey – Nandland Go Board (iCE40)

This repository documents my hands-on learning journey through FPGA development using the **Nandland Go Board** and the associated tutorials and course material provided by Nandland.

The goal of this project is to build a strong foundation in digital design, hardware description languages (Verilog/VHDL), and FPGA development workflows by following structured beginner-friendly projects.

---

## About the Nandland Go Board

The Go Board is a beginner-focused FPGA development platform based on the Lattice iCE40 FPGA family. It is designed to make learning FPGAs simple and accessible, with built-in peripherals such as:

- LEDs and push buttons  
- Dual 7-segment displays  
- VGA output  
- USB communication (power + programming + UART)  
- PMOD expansion support  
- On-board clock and flash memory  

More information: https://nandland.com/the-go-board/
